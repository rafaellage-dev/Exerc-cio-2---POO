# Exerc-cio-2---POO
Exercício avaliativo número 2 da disciplina de Programação Orientada a Objetos. Nesse exercício foi proposta a criação de um programa em Java que simulasse o funcionamento de um caixa eletrônico de banco, com as operações de consulta de saldo, depósito, saque e saída do programa. Além do arquivo principal (a Main.java), também foi criado o ConsoleUtils.java, que tem como função a limpeza do terminal após cada comando a fim de deixar a execução do programa mais limpa e organizada.
